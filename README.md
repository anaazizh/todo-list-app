# Python To-Do List Application

A command-line To-Do List Application built with Python.

## Features

- Add tasks
- View tasks
- Delete tasks
- Handles invalid menu selections
- Handles invalid task numbers
- Handles non-numeric deletion input
- Stores tasks in a Python list

## How to Run

1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Run:

```bash
python todo.py
```

## How to Use

Choose one of the menu options:

1. Add a task
2. View tasks
3. Delete a task
4. Quit
